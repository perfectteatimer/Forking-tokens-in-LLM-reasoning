# Forking Tokens in LLM Reasoning

[English](README.md) | **Русский**

Исследовательский проект по поиску точек ветвления в рассуждениях больших языковых моделей (LLM).

**Научный руководитель:** Gleb Rodionov.

## План проекта

### Чекпоинт 1. Знакомство с проектом и планирование

- Знакомство с научным руководителем, обсуждение темы и основных задач проекта.
- Составление примерного плана работы на год.
- Создание GitHub-репозитория.

### Чекпоинт 2. Изучение литературы

- Изучение основных статей по теме проекта.
- Знакомство с существующими подходами к поиску точек ветвления в рассуждениях LLM.
- Обсуждение возможных направлений работы.

### Чекпоинт 3. Первые эксперименты

- Выбор моделей и подготовка среды для экспериментов.
- Реализация и проверка нескольких базовых подходов.
- Обсуждение первых результатов и дальнейших шагов.

### Чекпоинт 4. ML-сервис

- Создание простого ML-сервиса на FastAPI.
- Реализация инференса выбранной модели через API.
- Точная задача сервиса будет выбрана на основе текущих результатов проекта.

### Промежуточная защита

- Представление проделанной работы и первых результатов.
- Обсуждение планов на второй семестр.

### Чекпоинт 5. Продолжение экспериментов

- Доработка существующих подходов или проверка новых идей.
- Проведение дополнительных экспериментов.
- Сравнение результатов и обсуждение дальнейшей работы.

### Чекпоинт 6. Анализ результатов

- Продолжение работы над выбранным направлением.
- Проведение дополнительных проверок и экспериментов.
- Анализ полученных результатов и возможных причин поведения моделей.

### Чекпоинт 7. Завершение проекта

- Проведение финальных экспериментов.
- Сбор и оформление результатов.
- Подготовка к итоговой защите.

### Итоговая защита

- Представление результатов проекта и основных выводов.

План предварительный и может меняться по ходу работы в зависимости от результатов экспериментов и обсуждений.
